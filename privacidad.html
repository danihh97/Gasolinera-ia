Política de privacidad

AhorraFuel es una web informativa para consultar y comparar precios de combustible y localizar estaciones de servicio.

Ubicación

La función «Cerca de mí» puede solicitar permiso del navegador para utilizar la ubicación del dispositivo. Esta función se utiliza para calcular distancias y ordenar los resultados por cercanía. El usuario puede rechazar el permiso.

Analítica

Si el usuario acepta las cookies de análisis, AhorraFuel utiliza Google Analytics 4 para obtener estadísticas sobre el uso de la web, como visitas y navegación.

Contacto

Para consultas relacionadas con AhorraFuel o esta política: ahorrafuel@gmail.com.
